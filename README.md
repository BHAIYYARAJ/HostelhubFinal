# HostelHub Mobile

Transform my existing HostelHub project into a real mobile-app experience, not a responsive website.

Keep all existing functionality, Supabase, authentication, database, booking logic, and desktop website unchanged.

For mobile, completely redesign the UI to feel like a native modern app, inspired by the attached HostelHub reference image.

Mobile requirements

Mobile-first layout

Edge-to-edge screens

Native-style top headers

Smooth app-like page transitions

Large touch-friendly buttons

Rounded cards and modern shadows

Mobile bottom sheets and modals

Sticky "Book Now" actions

Proper safe-area/status-bar support

No desktop navbar

No website footer

No desktop margins/max-width containers

Don't simply shrink the desktop UI

Create polished mobile screens for:

Home → Explore/Map → Hostel Details → Saved → Smart Picks → Bookings → Agreements → Complaints → AI Assistant → Profile

Also create a separate Owner mobile experience with Dashboard, Hostels, Bookings, Complaints and Analytics.

The most important requirement:

When I open HostelHub on my phone, it must feel like I opened a real app, not a website inside a phone.

Do not rebuild the backend. Reuse the existing functionality and data. Focus on making the mobile UI/UX feel like a professional production app.
